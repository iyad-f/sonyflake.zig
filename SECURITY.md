# Security Policy

## Supported Versions

Only the latest release of `sonyflake` receives security fixes.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public issues, pull requests, or discussions.

Instead, report them privately through GitHub's [Report a Vulnerability](https://github.com/iyad-f/sonyflake.zig/security/advisories/new) form. This keeps the report confidential until a fix is available.

You can expect an acknowledgement of your report as soon as possible, updates on the progress toward a fix, and coordination with you on the timing of any public disclosure.
